## 修订原因、取舍和边界

离线核对原私有启动器及其 freeze/index：`save()` 只限制管理记录和命令 stdout/stderr，
QEMU 直接写 `console.log`，该文件没有进入计数、完成索引或持续监督；VM 原 FSIZE
要求 infinity。因此原方案“沿用已验证有界 serial”的前提不成立。未进行新现场读取。

采用已在维护重启使用的 null 后端，保持虚拟串口配置而不保存其字节；代价是本次新
启动没有串口日志，启动诊断仅使用既有受限 stdout/stderr、身份/监听及 guest 返回。
启动故障即停，不为补日志重启。禁止自动回退到 file、FIFO、转发服务或新 VM 文件限制。
旧 serial 保留并按原要求核对。启动捕获4 MiB仍全额预留，不退款或挪给其它池。
