原输入及现场准入顺序执行一次，密码仅交 sudo 控制终端。窗口开始即消费；失败没有退款。

任一失败/未知/超时/漂移，停止后续动作；保留首因、已取得 progress 或明确缺失、退出/EOF、
marker/SSH/步骤事实及原输出。摘要不只截取 reason；不把 scan_complete 或统计前缀当 PASS。
不为凑完整报告增加读取，不重新扫描、自动调整预算、重连、强杀、清理、回滚或恢复。
