- job≤15 分钟，总三轮 job≤45 分钟；准备/六例/最终清理仍为 120/180/30 秒。probe 的20秒在准备预算内；每例仍原双钟20秒、17秒停止接收、最后3秒停止观察。世代创建、观测和退休消耗所在阶段剩余预算，无附赠窗口。
- E：128 MiB /32 tasks；每代 G：64 MiB /4 tasks；每代 B：64 MiB /16 tasks；swap=0、CPU≤一核、每例至多8 worker 后代不变。E 全轮累积约束保持，禁止同时保留多代运行。
- 新对象数量明确为 E 加最多7×4，累计创建≤29个 cgroup，任意时刻≤5个仍可见/可使用的登记目录对象；不是增加并发容量。rmdir后的内核延迟释放对象可能跨代，不宣称其数量≤5或元数据已即时回收；累计29仍是创建总量界。任一代未完整退休不得建立下一代。
- 每例双流128 KiB、全六例768 KiB、其他诊断256 KiB、报告2 MiB、普通文件32 MiB/128项全部不增。新字段/记录须在其中，超限留证并停止。
- 不增加依赖、不安装软件或内核、不改共享根控制器/账户策略/服务；不放宽 seccomp/UID/FD，不改生产模块、旧 Q2 runtime 或原业务输入。
