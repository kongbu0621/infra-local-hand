# Q2 固定本地来源补证：实施方案

- Authority：Owner；状态：**PROPOSED / Gate OPEN / 尚无本 scope 的 A/B/C/D**。
- Scope：`LH-Q2-LOCAL-SOURCE-EVIDENCE-v1`；R、需求编号、固定源和上限见[需求](REQUIREMENTS.md)。
- [架构](ARCHITECTURE.md)限定实现边界；本文件不授权先做可执行probe。

## L0：形成准确决定后再实现

1. 主代理复核三文档、来源采用与旧K范围的关系，确认没有公共真实路径、凭据或新执行权。
2. 将确定三文档及必要源摘要登记为真实文档提交A，保持原host/K三文档字节与历史标签。
3. Owner B只关闭本scope：准确R/A、7+4固定本地对象、两固定内核视图在新local-only
   分支复用、四原件窄来源采用、资源/无执行边界。保留准确决定、时间/event与稳定来源。
4. 独立C只登记CLOSED，不混入新实现、测试或运行配置。D以C为祖先，R→A→B→C→D
   顺序保持。没有准确B/C时，只继续文档及现有代码的只读核查/隔离验证。

不得把用户一般“继续”扩为H07监督准备、wrapper执行或普通writer内核例外；其它已获准
范围不因本提案而重新等待批准。

## 有意义的验证门槛

| 反例/边界 | 必须结果 |
| --- | --- |
| P/M/T长度/SHA错误、JSON重复key、source字段错配、目标重复/额外项、任意路径覆盖 | 任何现场read之前拒绝，不执行carrier |
| 原M结构不是49条/5树/7相邻、四控制项不精确、父目录关系不符 | 不猜测修复，不扩扫其它目录 |
| 缺准确新A/C/D或旧kernel链、包改工具后重算自带索引 | 未验证工具不执行，错误绑定准确阶段 |
| 普通文件noatime失败、symlink/hardlink、名称与fd替换、owner/mode/ACL或前后metadata改变 | 不降级、不读替代目标、不改元数据，实际失败保留 |
| 七项长度改变/等长内容改变 | 长度变只metadata，等长变保留hash差异；均不自动采用为历史、不输出raw |
| 四原件长度/摘要不符、短读、无EOF、超长 | 不把替代raw放进回执，不自动查别名或依赖 |
| 身份/groups变化、boot变化、内核挂载/ABI资格不合格 | 立即停止，不升级权限或改变namespace |
| marker既存/部分/状态不明 | 无读后续业务、无create/delete/接管，不恢复消费权 |
| 在输入接收、离线校验、读文件、编码时跨双钟界 | 从最早原点计算，停止并按真实范围报告，不重新取起点 |
| 输出raw base64膨胀、诊断与stdout共用2MiB、最终报告超限 | 有界错误，不截断为“完整回执”；输入启动/帧共池同样严格 |
| FS flags/statvfs成功或不支持 | 只记录事实，allocation_peak/durability仍false；不能启用writer |
| subprocess/execve/SSH/marker写入触点 | 无调用路径；测试监测到调用即失败；准确包验证后的RAM模块装载不等于执行控制脚本 |
| K4五树或七旧pin被加入新的现场读取 | 除精确11项内的文件外拒绝；旧K4只历史引用，不报告同刻完整49对象 |

至少一组真实普通身份隔离文件验证held/noatime、前后metadata与稳定身份；支持环境中的
固定kernel读者已有真实普通身份验证可作为准确版本回归依据，必要时仅复测受影响边界。
root或mock不能代替普通身份现场事实。环境限制如实SKIP/BLOCKED。
不为本低影响补证无目的重跑整个仓库；测试足够验证受影响合同后固定D。

完整私有P/M/T离线派生应得到精确11项、10,490,352有效内容上限及10,490,363实际读取上限；两次组装包逐字节
一致；包的直接成员、decoded上限、全部工具blob及最终wire总量按实际字节验证。
真实PTY只验证接收/终端恢复/最早原点，不借错机或模拟输入取得原host PASS。

## L5交付与回执复核

交付前先在私有资料中给用户一套完整可操作的材料，不要求先批准模糊动作。
原host只通过本机普通终端运行已批准准确包；当前工作容器不冒充原host，没有已授权
连接时不猜SSH、IP或凭据。L5先安排一次调用，只执行固定观察，无自动重试、collector或full-run。再次同范围观察须由Owner明确发起，不能因收到部分结果自行重跑。

返回JSON先固定原字节SHA/长度，严格解析，核对D/package/源摘要、逐项范围、上限、
身份/双钟、11对象与回执raw一致性。用户粘贴是原回传证据，不自动称独立签名stdout。
与K4比较时保留两个观察时间，当前allocated差异仅解释事实；不拼成同刻完整快照。

wrapper原文仅离线审查解释器、argv、依赖、重定向和环境。若`memory_wrapper_argv`
不支持或依赖未取证，记录准确差额；不能修改原脚本、绕过脚本或为通过而改SSH参数。
W2启动脚本只证明其文本声明，不证明当前VM实际配置；当前版本/域/时钟仍需各自来源。

## 完成定义与下一入口

L1–L6完成意味着：准确范围有实现/隔离验证/精确交付，且原host返回的实际观察已
逐项核对或明确阻断。K4原限定完成度、旧两次INCOMPLETE及全部历史证据保持。

无论11项是否齐全，本scope都不能关闭H07、完整账单、FS分配峰值/持久资格或Q2。
后续可自主用这些材料完成原范围内来源映射/组件修复/隔离验证；若需新增guest取证、
监督准备、source adoption、预算或将内核例外扩到writer，先形成准确受影响三文档
及A，不能把本scope作为授权。原scope无关工作继续，不重新索取同范围批准。
