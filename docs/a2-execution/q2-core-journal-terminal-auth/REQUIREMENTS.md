## 验收与不变边界

当前账号必须本来就有执行该固定 sudo 命令的权限，且本人能完成其既有认证；本提案不赋予不存在的权限。
无真实前台终端时在新现场窗口之前拒绝；认证拒绝、超时、终端变化、writer 未知或任一旧条件失败即停止。
只有原报告、真实退出、EOF、全部身份及内容校验通过，才进入下一个原步骤。密码正确不等于检查通过。

原五镜像选择器、内容/UUID/挂载关系、正常锁、备份、15s/900s/780s 和源文件上限不变。
原 host 每相关设备 1296 MiB/370 inode，旧承诺 264 MiB/80 inode，备份 320 MiB、镜像 576 MiB、
capture 8 MiB/32 inode，120 CPU-s/512 MiB 部分观测、AS 256 MiB/FD 128/至多八控制子进程均保持。
writer 输入/stdout 各 65536 B、stderr 4096 B、payload 32768 B；认证提示也纳入既有捕获预算。
sudo 可直接向 TTY 输出提示或审计消息，不能宣称该独立通道也被管道字节上限完整覆盖；不新增终端录制器。
