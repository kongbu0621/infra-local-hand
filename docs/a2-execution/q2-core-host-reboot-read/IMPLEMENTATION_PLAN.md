1. 本A只包含三文档；HB1前普通故障输出修复须完成验证/正常发布。核对RP1/RP2固定
   私有来源并生成仅供评审的完整请求：准确R/A、固定本机目标/列表、无远端出站、
   一次调用、限制/费用和终态。没有新reader、可执行原型、执行归档或现场读取。
2. Owner针对准确A关闭HB1–HB2；独立C只登记准确决定和CLOSED，再开始D。不能用
   “重启过宿主机”或一般推进指令伪造这项新读取的Owner决定，不能squash C与D。
3. HB1在既有E3核心辅助代码中实现一个固定本机reader及独立离线消费者，复用有界
   文件保护、管道捕获和故障输出。私有caller仅冻结参数/来源/输出；产品CLI/MCP
   不新增入口，不扩展NAS/插件/诊断功能。所有新准备占用已列出的单一准备池。
4. 隔离测试覆盖真实临时文件与本地管道：相同/不同boot、PID缺失/复用、pidfile坏值/
   symlink、六镜像身份/保护漂移、监听空/占用、实际非零退出、双EOF缺失、超限、
   失败保留、重放拒绝，以及失败后无SSH/VM动作/扩展查询。只测新reader，不调用旧
   caller。新事实不能靠修改旧冻结获得，测试PASS不能表示核心现场PASS。
5. 核验精确命令/路径清单、输入数量、持有周期、真实FD256、AS512 MiB和完整CPU/RSS
   合计、单记录/双流/总输出及两个准备池。实际私有字段与公开脱敏说明一一对应。
6. 必要实现正常PR合入main，准确D自己的首次CI、独立安装、来源与输入/调用器冻结
   完整通过后，才调用HB2一次。批内不逐项再审批；普通修复未完成不能提前现场试跑。
7. HB2在正常本机用户视图中完成固定读取；只一次ss本机过滤查询，无SSH。父捕获
   完成后独立核验全部原件及真实退出，写单独终态，旧RP1/RP2和全部caller字节不变。
8. 根据事实记录“是否需要重新启动/是否已有可验证实例/是否有冲突”，保留UNKNOWN。
   后续启动、guest核验、维护与07a接续另据事实定案；本批不预先实现或发行它们。
