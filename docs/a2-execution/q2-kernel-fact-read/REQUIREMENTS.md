## 保留约束与剩余风险

固定 boot、五组对象定位、七个旧 pin、唯一未发行批次、所有预算和冻结 runtime
均不变。不能用当前读取证明消费路径原本不存在，或将部分观察升级为联合准入。
H07 首次远端有效期限、完整费用、wrapper 来源及文件系统持久资格仍独立缺证。

procfs 是内核视图；读取可能触发内核内部计算/缓存及现有系统审计，不承诺整机
零写入，也不把未知日志费用填零。普通证据文件不进入该例外。可信内核及不被
范围外管理员恶意改动的挂载/身份仍是环境假设；元数据检查不是防御恶意内核的证明。
执行限定原 host 本机终端及其对齐的 proc/PID namespace；该对应是明确环境
假设，不由 boot 或 mount ID 单独证明，已知不满足时停止而不改 namespace。
成功标准是这两处专用读取在普通身份可验证，或准确报告剩余阻断；不承诺全流程通过。
